# Abstract

SchemaSmith is a Track 1 entry for the Lexsi AI Safety and Alignment Hackathon, problem 5, structured output and extraction. The task is to turn a messy multilingual support ticket into one JSON object that satisfies a data contract. The contract covers ticket id, customer tier, category, severity, order reference, refund amount, and language, plus the rule that a refund amount is present only for a billing ticket. The core model is Cohere Labs Tiny Aya Global (`CohereLabs/tiny-aya-global`), one of the seven listed Cohere models, and the only model this submission trains or scores. Training uses LoRA so the run fits a free T4 or a small Hugging Face Jobs GPU.

The contract is the gate at each step. A generator builds a small set of tickets in eight languages with labels that already validate. CuratorKIT, used as an external tool, cleans and deduplicates that set. Rows whose labels fail the contract are dropped before training. AlignTune's TRL backend runs supervised fine-tuning, then a direct preference pass. Preference pairs use the labeled JSON as the chosen answer and a planted failure as the rejected answer: broken JSON, a missing field, an extra field, the wrong language code, or a refund amount that is not in the ticket. The preference pass starts from the supervised checkpoint. A new LoRA is trained on those weights.

Evaluation uses the same contract. The held-out compare scores the base model, the supervised adapter, and the preference adapter on parse rate, schema-valid rate, field-level exact match, unsupported values for ids and amounts, and non-English contract-valid rate. AuditKIT can sit beside that scorer. Those numbers are not in this draft. They stay TBD until the compare command writes a results file and the README table is regenerated from that file only.

The repository is MIT. Tiny Aya weights are CC-BY-NC-4.0. Lexsi source-available tools are dependencies, not copied into the tree. A Gradio page shows the contract, a sample ticket, and the validator. Its default mode uses labeled examples and does not load the model. Commands, seeds, and notebook steps are in the reproducibility guide.
